# Collections

Collections no java, no meu entendimento, é basicamente uma api que fornece um conjunto de classes e interfaces para armazenar e manipular grupos de objetos. Ela inclui estruturas de dados como listas, conjuntos, filas e mapas, além de algoritmos para ordenação, busca e manipulação desses dados.

E acaba incluindo eles:
* #### List
* #### Set
* #### Queue
* #### Map

Cada um deles tem um papel especial, no meu dia a dia, eu acabo usando mais
o List e Map, e de vez em quando utilizo o Set.
<br> Agora o Queue, parece ser interessante para fila, talvez para algum tipo de processamento em lote, mas ainda não tive a oportunidade de usar ele.
